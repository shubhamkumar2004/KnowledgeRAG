# KnowledgeRAG

An open-source Retrieval-Augmented Generation (RAG) framework for building AI assistants over websites and documents using entirely local models.

## Features

- Website Crawling
- Data Cleaning
- Smart Chunking
- SentenceTransformer Embeddings
- ChromaDB Vector Store
- Hybrid Retrieval (Semantic + Keyword)
- Local LLM (Ollama + Qwen2.5)
- FastAPI Backend
- React Frontend
- Hallucination Prevention
- Benchmark Testing

## Tech Stack

Backend
- Python
- FastAPI
- ChromaDB
- SentenceTransformers
- Ollama
- Qwen2.5

Frontend
- React
- Vite

## Current Demo

The current implementation demonstrates the framework using the Ekta Navnirman Trust website.
